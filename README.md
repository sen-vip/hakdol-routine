# 🐣 학돌 루틴집

학교 행정실에서 반복되는 업무를 **주기별·담당업무별로 빠르게 찾아볼 수 있는 업무 참고 도구**입니다.

매월, 매주, 분기, 반기, 연간 등 반복되는 업무를 한곳에서 확인하고
우리 학교에서 실제로 처리하는 시기도 간단히 기록해둘 수 있습니다.

# 🔎 주요 기능

## 📅 주기별 업무

학교 행정실에서 반복적으로 처리하는 업무를 주기별로 확인할 수 있습니다.

* 매월
* 매주
* 분기
* 반기
* 연간 등

업무마다 기본적인 처리 주기와 간단한 실무정보를 함께 확인할 수 있습니다.

---

## 🏫 우리학교 주기 기록

학교마다 실제 업무 처리 시기가 다른 점을 고려해
각 주기업무에 **우리학교의 실제 처리 시기**를 한 줄로 기록할 수 있습니다.

예시

* 도시가스 정기검사 → `10월`
* 저수조 청소 → `여름방학`
* 승강기 정기검사 → `매년 3월쯤`
* 소방시설 작동점검 → `11월`

저장한 내용은

`🏫 우리학교 · 10월`

형태로 업무 카드에서 바로 확인할 수 있습니다.

별도의 복잡한 일정 설정 없이
**“우리 학교에서는 이 업무를 언제 했더라?”**를 기억하기 위한 간단한 기록 기능입니다.

우리학교 주기는 브라우저에 저장되며 언제든 수정하거나 삭제할 수 있습니다.

# 👤 담당업무별 확인

자신이 담당하는 업무를 선택해 필요한 업무만 모아볼 수 있습니다.

여러 담당업무를 함께 선택할 수 있어
학교별 업무분장에 맞게 활용할 수 있습니다.

---

# 🔍 업무 검색

업무명이나 관련 키워드로 필요한 업무를 빠르게 찾을 수 있습니다.

전체 목록을 일일이 확인하지 않아도
궁금한 업무를 바로 검색할 수 있습니다.

---

# 💡 이렇게 활용해보세요

처음 맡은 업무의 전체 흐름을 파악할 때

> 이 업무는 매달 하는 건가?
> 분기에 한 번 하는 건가?

확인할 수 있습니다.

오랜만에 돌아온 업무가 있다면

> 이거 우리 학교에서는 언제 했었지?

`우리학교 주기`에 간단히 기록해두고 다음 업무 때 바로 확인할 수 있습니다.

---

# 💾 데이터 저장

`우리학교 주기`에 입력한 내용은 사용 중인 브라우저의 로컬 저장소(localStorage)에 저장됩니다.

* 별도의 회원가입 없음
* 서버에 입력 내용 전송하지 않음
* 업무별로 각각 저장
* 새로고침 후에도 유지

단, 브라우저 데이터를 삭제하거나 다른 PC·브라우저를 사용하면 저장 내용이 이어지지 않을 수 있습니다.

---

# 📱 사용 환경

별도의 프로그램 설치 없이 웹브라우저에서 바로 사용할 수 있습니다.

PC와 모바일 화면에 맞게 사용할 수 있도록 구성했습니다.
