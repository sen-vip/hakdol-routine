# 학돌 루틴집 v3.2.8

학교 행정 업무를 월별 타임라인과 담당업무 기준으로 확인하는 학돌루틴 3.2.8 버전입니다.

## 3.2.8 업데이트

- 주기업무에 `우리학교 주기` 한 줄 기록 기능 추가
- `10월`, `여름방학`, `매년 3월쯤`처럼 학교의 실제 처리 시기를 자유롭게 입력 가능
- 입력값은 업무별로 브라우저 `localStorage`에 저장되어 새로고침 후에도 유지
- 주기업무 미리보기와 전체 목록에서 바로 기록·수정·삭제 가능
- 저장된 주기는 `🏫 우리학교 · 내용` 형태로 간단히 표시
- 날짜 선택기나 복잡한 주기 설정 없이 50자 이내 한 줄 입력으로만 구성
- 모바일에서도 입력·저장·수정이 가능하도록 반응형 UI 적용

## 유지 사항

- 기존 월별업무·상황업무 데이터와 화면 구조 유지
- 기존 체크/메모/검색/월 선택/필터/정렬 기능 유지
- 원본 업무 데이터와 사용자 입력값을 분리하여 저장
